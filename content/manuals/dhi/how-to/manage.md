在 Docker Hub 的**管理**页面，你可以统一管理组织内已同步的 Docker 加固镜像（DHI）仓库以及自定义的 DHI 镜像。

## 管理已同步的 Docker 加固镜像

要管理已同步的 DHI 仓库：

1. 打开 [Docker Hub](https://hub.docker.com) 并登录。
2. 点击 **我的 Hub**。
3. 在命名空间下拉框中选择你的组织。
4. 依次选择 **加固镜像** > **管理**。

   在该页面，你可以查看所有已同步的 DHI 仓库，以及它们对应的源仓库。

5. 在目标仓库最右侧的菜单图标上点击。

   可选操作包括：

   - **自定义**：基于源仓库创建自定义镜像。
   - **停止同步**：停止同步该 DHI 仓库。

## 管理自定义的 Docker 加固镜像

要管理自定义的 DHI 仓库：

1. 打开 [Docker Hub](https://hub.docker.com) 并登录。
2. 点击 **我的 Hub**。
3. 在命名空间下拉框中选择你的组织。
4. 依次选择 **加固镜像** > **管理**。
5. 点击 **自定义镜像**。

   在该页面，你可以查看所有自定义的 DHI 仓库。

6. 在目标仓库最右侧的菜单图标上点击。

   可选操作包括：

   - **编辑**：修改该自定义镜像。
   - **新建**：基于源仓库创建新的自定义镜像。
   - **删除**：删除该自定义镜像。
