本页面包含 Docker Build Cloud 版本中的新功能、改进、已知问题和错误修复信息。

## 2025-02-24

### 新增功能

新增了**构建设置**页面，您可以在该页面为组织中的云构建器配置磁盘分配、私有资源访问和防火墙设置。这些配置有助于优化存储、启用对私有仓库的访问和保护出站网络流量。
