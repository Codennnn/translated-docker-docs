要使用 Docker for GitHub Copilot 扩展，您首先需要为您的组织[安装](#install)该扩展，并在组织中[管理](#manage-policies) Copilot 的相关策略。

## 先决条件

开始之前，请确保您已在 GitHub.com 上登录到您的 GitHub 账户。

## 安装

为您的 GitHub 组织安装 Docker for GitHub Copilot 扩展：

1. 访问 GitHub Marketplace 中的 [Docker for GitHub Copilot](https://github.com/marketplace/docker-for-github-copilot)
   应用页面。

2. 选择页面顶部的 **添加** 按钮。

3. 在 **定价和设置** 下，选择您要安装扩展的组织，然后选择 **免费安装**。

4. 选择 **完成订单并开始安装** 按钮。

5. 选择您要使用 Docker for GitHub Copilot 扩展的仓库，然后点击 **安装** 完成设置。

## 管理策略

如果您为 GitHub 组织启用此扩展，还需要启用 Copilot Extensions 策略。有关说明，请参阅
[在您的组织中为 GitHub Copilot Extensions 设置策略](https://docs.github.com/en/copilot/managing-copilot/managing-github-copilot-in-your-organization/setting-policies-for-copilot-in-your-organization/managing-policies-for-copilot-in-your-organization#setting-a-policy-for-github-copilot-extensions-in-your-organization)。
