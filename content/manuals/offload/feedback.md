您可以通过多种方式为 Docker Offload 提供反馈。

## 快速调查

分享您的想法最快捷的方式是填写这份简短的
[Docker Offload 反馈调查问卷](https://docker.qualtrics.com/jfe/form/SV_br8Ki4CCdqeIYl0)。
只需一分钟，即可帮助 Docker 团队改进您的使用体验。

## 应用内反馈

在 Docker Desktop 仪表板的每个视图中，都有一个**"提供反馈"**链接。点击后会打开反馈表单，您可以直接与 Docker 团队分享想法和建议。

## 在 GitHub 上报告错误或问题

如需报告错误或问题，请访问以下链接：
- [Docker Desktop for Mac 问题反馈](https://github.com/docker/for-mac/issues)
- [Docker Desktop for Windows 问题反馈](https://github.com/docker/for-win/issues)
- [Docker Desktop for Linux 问题反馈](https://github.com/docker/desktop-linux/issues)
